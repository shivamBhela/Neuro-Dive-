# P5 — retired collectible system

The Verdant Seed, Sun Seal and Amethyst Prism, their tracker/persistence, prefabs, runtime scripts, HUD panel, prompts, test stations and decorative focus rings have been removed by the final design decision of 2026-10-14.

P5 creation and collection test menus are retired. Use **Tools > Lost Worlds > P5 > Validate Relic Removal** to check all realm/demo scenes and prefabs for retired objects, missing references and missing scripts. The same audit runs in P13/P14 validation.

The separate 36 Journey Tokens and their session ledger/HUD remain. GRAB/ACTIVATE still operate on environmental objects. No collectible is required for realm transitions or Journey Complete.

[Current manual checks and regression results](../RelicRemoval/README.md). Older text/image test reports in this folder are historical evidence only.
